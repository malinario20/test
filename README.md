# Сайт аренды техники — статическая версия

Сервер не нужен. Откройте `index.html` двойным кликом или выложите папку на любой статический хостинг (Vercel, GitHub Pages, Netlify, Cloudflare Pages).

- Сайт: `index.html`
- Админка: `admin/index.html` (пароль по умолчанию `admin`)

## Админка
Слева разделы в том же порядке, что блоки на сайте: Шапка, Первый экран, Техника, Как арендовать, Цены и скидки, Вопросы, Контакты и подвал. Кнопка «Предпросмотр» показывает сайт рядом. «Сохранить» применяет правки в этом браузере.

## Как показать изменения всем
Раздела «Настройки» в админке больше нет: правки сохраняются в браузере. Чтобы они появились у всех посетителей, значения нужно прописать в `data/config.js`.

## Заявки в Telegram
Заявки принимает `api/order.js` (Vercel подхватывает папку `api` сам). Токен бота хранится только в переменной окружения Vercel `BOT_TOKEN`. ID чата вписывается в админке, раздел «Telegram»; если там пусто, берётся переменная `CHAT_ID`.

## Проверка на своём компьютере (без Vercel)
1. Скопируйте `.env.example` в файл `.env` и впишите `BOT_TOKEN=` (токен от @BotFather).
2. Запустите `node dev-server.js` (нужен Node.js 18+).
3. Откройте http://localhost:3000, админка: http://localhost:3000/admin/. ID чата впишите в админке (раздел «Telegram»), там же есть кнопка тестовой заявки.
Файл `.env` не попадает в git (он в `.gitignore`), на Vercel вместо него используются Environment Variables.
